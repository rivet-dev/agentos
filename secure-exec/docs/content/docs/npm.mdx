## Install into a context

`secure-exec/npm` installs packages into a [context](/secure-exec/docs/contexts).
A context is required, because an install into a VM that is thrown away after
the call would do nothing.

<CodeSnippet file="secure-exec/examples/npm/src/index.ts" />

- Installing needs the network, which is denied until you allow it.
- Packages install into the working directory, `/workspace`. Inline code
  resolves imports from its `filePath`, so set `filePath` to a path inside
  `/workspace` when you import an installed package.
- `install({ context })` with no package list installs the dependencies of the
  `package.json` in the working directory.
- `runScript` and `runPackage` work like `npm run` and `npx`.

## Mount packages you already have

If the packages are already on the host, mount them instead. There is no
network access and no install step, so it also works in one-shot calls.
