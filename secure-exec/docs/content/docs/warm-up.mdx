---
title: "Warm-up"
description: "Pre-start the Secure Exec sidecar with init so the first call is fast."
---

Secure Exec runs VMs inside one shared sidecar process. The first call starts
it. Call `init()` when your server boots to pay that cost ahead of time.

<CodeSnippet file="secure-exec/examples/quickstart/src/warm-up.ts" />

`init` takes no options and is safe to call more than once. The sidecar is shared
by every call in the process, and it never keeps a script alive on its own: when
no VM is running, your process can exit normally.
