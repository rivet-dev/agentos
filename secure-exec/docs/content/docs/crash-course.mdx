The whole API is a handful of functions across three entry points.

| Import | Functions |
|---|---|
| `secure-exec` | `evaluate`, `execute`, `createContext`, `init` |
| `secure-exec/typescript` | `evaluate`, `execute`, `check` |
| `secure-exec/npm` | `install`, `runScript`, `runPackage` |

## Run code

`evaluate` returns the JSON value of one expression. `execute` runs a module
for its side effects. Each call gets a fresh VM that is disposed when the call
finishes.
