---
title: "Browser Automation"
description: "Run a packaged browser CLI as ordinary agentOS software."
---

Browser automation is ordinary VM software. Build the CLI into an immutable
`.aospkg`, host it at an HTTPS URL, and include that source in actor creation
config. The `software/browserbase` package exposes the `browse` command.
Supply your package URL, digest, CLI arguments, process environment, and permissions
explicitly. Guest networking is denied by default. Your permissions policy must
allow the provider hosts the CLI needs, including DNS and outbound connections.

<CodeSnippet file="examples/hosted/browser.ts" />

The guest receives only the credentials explicitly passed to the process
environment. The actor does not provide a browser-specific API.
