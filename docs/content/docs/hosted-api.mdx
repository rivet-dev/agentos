`createAgentOsClient` creates a RivetKit client typed from the native Rust
`agentOS` actor registry. Supply the control-plane endpoint, namespace, and
credentials for your deployment. The factory loads its hosted transport only
when called.

## Action groups

| Group | Operations |
| --- | --- |
| `config` | Read, replace, or patch desired configuration with revision checks. |
| `vm` | Inspect lifecycle state or restart the VM. |
| `filesystem` | Read, write, list, move, remove, export, and inspect guest files. |
| `process` | Run or spawn a command, inspect its status, write stdin, signal it, and replay output. |
| `terminal` | Open a terminal, exchange input/output, resize, wait, and close. |
| `contexts` | Create, inspect, reset, and delete retained language contexts. |
| `javascript`, `typescript`, `python` | Execute or evaluate code and manage language packages. |
| `network` | Fetch from the VM, pull a bounded response stream, and create expiring preview leases. |
| `software` | Install, uninstall, or list remote registry packages. |
| `cron` | Schedule, list, and cancel durable commands. |

Action names match the registered Rust names, such as `filesystem.writeFile`
and `process.run`. The generated contract exports `AGENTOS_CONTRACT_HASH` and
`AGENTOS_API_VERSION` for diagnostics. Internal reserved actions are excluded
from the public client.

## Ownership and lifecycle

Process, terminal, and fetch-stream handles include the VM generation. A handle
from a previous generation fails after restart instead of acting on a new
resource with the same numeric ID. Configuration responses include desired and
applied revisions so callers can distinguish a saved change from one requiring
a restart.

The control plane authorizes actor access. Use a credential scoped to the actor
and allowed operations when giving a client to an untrusted user. The hosted
actor independently rejects configuration that could open a host directory,
execute a host callback, or install a local package path. Guest filesystem,
process, and network permissions are enforced by the native sidecar.

## Binary data, errors, and cancellation

Keep RivetKit's default binary encoding for file bytes, output replay, and
network responses. The generated DTOs accept `Uint8Array` and exact integer
values where the Rust contract requires them. Do not coerce generations,
revisions, or cursors beyond JavaScript's safe integer range to `number`.

Action failures carry the server's typed error code. Bounds apply to the full
encoded action envelope as well as its contents. Split large transfers, set
execution timeouts, and use the generated process and stream cancellation
actions. Always dispose the client when finished. See
[hosted limits](/agentos/docs/actor-limits).

## Embedded API

The embedded API exposes trusted callbacks and host-backed mounts in addition
to guest execution. Read more in the
[embedded API quickstart](/agentos/docs/quickstart-embedded).
