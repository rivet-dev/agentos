agentOS gives each agent a lightweight VM with files, processes, a shell, and
networking. It is powered by WebAssembly and V8 isolates, the same technology
behind Chrome and Cloudflare Workers, and exposes Linux-style POSIX files,
processes, and sockets.

## Why agentOS

- **Library, not extra infrastructure.** Install agentOS from npm and run it inside the backend process you already operate.
- **WebAssembly and V8, not a microVM.** V8 isolates run JavaScript, and WebAssembly runs compiled tools such as the shell, coreutils, and Python in the same compact runtime.
- **Direct function calls, not extra APIs.** Connect agents to your application with [host functions](/agentos/docs/host-functions) instead of another network service.
- **Scoped access, not exposed credentials.** Bind trusted host functions without giving the agent your raw secrets.
- **One process, not a VM per agent.** Many isolated VMs share one runtime instead of each duplicating a full microVM stack.
- **Runs anywhere.** Deploy on standard Linux infrastructure without a hypervisor or nested virtualization.

A cold start takes about 5 ms and a shell workload uses about 22 MB of memory.
See [Performance](/agentos/docs/performance) for the benchmarks and how to run
them yourself.

- **Library:** `@rivet-dev/agentos-core` runs VMs inside your Node.js backend.
  Your application owns the VM's lifecycle, persistence, and access to host
  resources such as [host functions](/agentos/docs/host-functions) and
  [mounts](/agentos/docs/filesystem#mounts).
- **Hosted:** the prebuilt `agentOS` Rivet Actor gives each VM a durable ID,
  versioned configuration, replayable output, and expiring previews. Control
  it from `@rivet-dev/agentos` or plain HTTP.

|  | [Library](/agentos/docs/quickstart) | [Hosted](/agentos/docs/quickstart-hosted) |
|---|---|---|
| **Runs** | Inside your process | Durable instance on Rivet Cloud or [self-hosted](/agentos/docs/self-hosting) |
| **Lifecycle** | Runs until `dispose()` or process exit | Sleeps when idle unless a process is running |
| **Clients** | Your backend | Your backend, or browsers with a scoped JWT |
| **Preview URLs** | None | Expiring preview URLs |
| **Host access** | Host functions, host directory mounts, local software | Serializable configuration only |

## What's in a VM

| Group | What it does |
| --- | --- |
| `process` and `terminal` | Run commands, manage child processes, and open interactive PTY sessions. See [Processes & Shells](/agentos/docs/processes). |
| `filesystem` | Read, write, and list files, and attach mounts. See [Filesystem](/agentos/docs/filesystem). |
| `javascript`, `typescript`, `python` | Run code, install npm and pip packages, and type-check. See [Node.js](/agentos/docs/javascript) and [Python](/agentos/docs/python). |
| `network` | Reach servers running in the VM and create preview URLs. See [Networking & Previews](/agentos/docs/networking). |
| `software` | Install `.aospkg` command packages. See [Software](/agentos/docs/software). |
| `cron` | Run scheduled commands. See [Crons & Schedules](/agentos/docs/cron). |
