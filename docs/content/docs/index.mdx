agentOS provides isolated filesystem, process, terminal, language, and networking
APIs in a lightweight VM.

<CardGroup>
  <Card title="Hosted actor" href="/agentos/docs/quickstart">

  </Card>
  <Card title="Embedded Core" href="/agentos/docs/quickstart-embedded">
    Run a VM inside a trusted Node.js backend.
  </Card>
  <Card title="Software" href="/agentos/docs/software">
    Install immutable `.aospkg` command packages.
  </Card>
</CardGroup>

The hosted actor is a thin wrapper around the same Core runtime. It adds durable
actor configuration, sleep/wake lifecycle, previews, cron, and Rivet events. It
does not accept executable TypeScript actor code, host callbacks, or host paths.

Read the [hosted actor API](/agentos/docs/actor-api) for configuration,
lifecycle, pull transport, events, generated types, and compatibility metadata.

## Embedded API

Use embedded Core when a trusted backend owns the VM process and host functions.
Read more in the [embedded API quickstart](/agentos/docs/quickstart-embedded).
