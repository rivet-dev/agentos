---
title: "Host Bindings"
description: "Expose trusted host functions to embedded agentOS VMs."
---

Bindings run trusted callbacks in the embedding Node.js process and expose them
to guest programs as typed commands. They are an embedded-Core-only capability.

<CodeSnippet file="examples/bindings/exec-javascript.ts" />

The hosted `agentOS` actor cannot accept callbacks, closures, host objects, or
binding implementations. Put product-specific callbacks in your own trusted
application actor and use embedded Core there.
