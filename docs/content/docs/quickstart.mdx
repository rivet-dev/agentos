## Install

```bash
npm install @rivet-dev/agentos rivetkit
```

Deploy the prebuilt Rust binary with the `actor` entry point in your RivetKit
runtime. Its registered actor name is always `agentOS`.

The hosted actor accepts whitelisted serializable filesystem descriptors and
HTTPS software URLs. Host bindings, host mounts, local package paths, and custom
actor hooks are embedded-Core-only capabilities.
