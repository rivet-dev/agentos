Use agentOS as a library from your Node.js process. The library starts a local
sidecar that owns each VM. To create
durable VMs by ID and control them over HTTP instead, see the
[hosted quickstart](/agentos/docs/quickstart-hosted).

## Which one should I use?

|  | [Library](/agentos/docs/quickstart) | [Hosted](/agentos/docs/quickstart-hosted) |
|---|---|---|
| **Runs** | In a local sidecar started by your process | Durable instance on Rivet Cloud or [self-hosted](/agentos/docs/self-hosting) |
| **Lifecycle** | Runs until `dispose()` or process exit | Sleeps when idle unless a process is running |
| **Package** | `@rivet-dev/agentos` | `@rivet-dev/agentos` or plain HTTP |
| **Clients** | Your backend | Your backend, or browsers with a scoped JWT |
| **Preview URLs** | None | Expiring preview URLs |
