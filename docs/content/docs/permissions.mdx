---
title: "Permissions"
description: "Constrain untrusted guest filesystem, process, and network access."
---

Pass a serializable permission tree in creation config or a later complete
`config.set` replacement. The trusted sidecar enforces it for every guest
operation.

Both defaults profiles allow VM-local networking. External networking and DNS,
including model-provider endpoints, require an explicit permission grant.
Omitted permission scopes retain their sidecar-owned defaults.

The permission tree has `fs`, `network`, `childProcess`, `process`, and `env`
scopes. Each scope accepts `"allow"`, `"deny"`, or a rule set. The library also
supports a `hostFunction` scope for callbacks supplied by the embedding
process. The hosted actor does not accept host functions.

`network: "deny"` blocks traffic crossing the VM boundary, including DNS, while
allowing guest listeners and guest loopback. A custom network rule set replaces
the whole network scope; include local listen and loopback rules if they should
remain allowed.
