---
title: "Networking & Previews"
description: "Proxy HTTP requests into VM ports and create expiring preview routes."
---

`network.fetch` proxies one bounded HTTP request to a VM loopback port.
`network.fetchStream.start/read/cancel` provides bounded chunked response
delivery.

Guest listeners bind only inside the VM. Use `network.fetch` to send a request
to a VM-local port. The caller owns backpressure when reading a streamed
response.

Preview paths are expiring records in actor SQLite. `network.preview.create`
returns a route to a VM-local port.

Use `network.preview.expire` to revoke a token before its deadline. Preview
requests are served through the actor request handler and never expose arbitrary
host routes.

Guest loopback traffic stays inside the VM. `network: "deny"` blocks outbound
traffic and DNS while leaving VM-local listeners and loopback working. Host
requests and previews enter through VM-local loopback; they do not publish a
guest listener on the host network.
