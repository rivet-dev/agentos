`network.fetch` proxies one bounded HTTP request to a VM loopback port.
`network.fetchStream.start/read/cancel` provides bounded chunked response
delivery.

Use `network.preview.expire` to revoke a token before its deadline. Preview
requests are served through the actor request handler and never expose arbitrary
host routes.

## Embedded API

Embedded Core provides direct HTTP request methods without the RivetKit action
envelope or hosted preview leases. Read more in the
[embedded API quickstart](/agentos/docs/quickstart-embedded).
