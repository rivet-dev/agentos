`@rivet-dev/agentos-core` runs the same VM runtime without Rivet actor
lifecycle. Your application owns VM identity, persistence, and disposal.
Its native sidecar and platform package must match the installed agentOS
version. If resolution reports a missing or mismatched binary, reinstall the
packages; `AGENTOS_SIDECAR_BIN` can select a custom local build.

## Embedded-only capabilities

Because the embedding process is trusted, Core can accept values that cannot
cross the hosted actor boundary:

- host bindings;
- host-directory and callback-backed mount plugins;
- external VM providers;
- trusted local `.aospkg` paths;
- custom schedule drivers and sidecar placement.

<CodeSnippet file="examples/embedded/config-reference.ts" title="config-reference.ts" />

The hosted actor uses a smaller generated configuration type and a fixed
filesystem registry. It never serializes callbacks or exposes a host path.
